# Northline

Frontend for an AI-assisted commercial construction bid platform. The first workspace is Summit Coatings, a Nashville painting subcontractor. Data and actions are simulated in the browser.

## Scripts

- `npm run dev` starts the app
- `npm run check` runs formatting, lint, typecheck, and unit tests
- `npm run build` creates a production build
- `npm run test:e2e` runs Playwright

Demo roles in the header are not authentication. A future backend must enforce permissions.
